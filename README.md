# Slack UI sandbox

A dependency-free Slack-style app shell prototype focused on channel sidebar behavior.

## Features

- Workspace rail and channel sidebar layout
- Channel and direct message lists with muted, online, unread, and active states
- Unread badges that clear when a conversation is opened
- Conversation header and message list that update with the active channel
- Simple message composer for the active conversation

## Run

Open `index.html` in a browser, or serve the directory with any static file server.
